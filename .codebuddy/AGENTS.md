# Agent-Skills for CodeBuddy

Select the relevant skill from its description; use `cs-using` only when routing is unclear.
Read one primary workflow and only the supporting resources the task needs. Reuse existing
authorization, decisions and valid evidence. Team workflows require explicit invocation.
Persona dispatch is limited to `cs-frontend-lead` assigning Cocos client work to
`cs-cocos-specialist`, and `cs-backend-lead` assigning Cocos server work to
`cs-network-programmer`. Both workers only execute; their assigning lead decides design changes.
Other persona orchestration stays with the host. Complete the selected workflow's verification.

Create missing parent directories before writing new files when the host's write tool
requires it. For skill-pack authoring conventions, read `CODEBUDDY.md` only when editing skills.
