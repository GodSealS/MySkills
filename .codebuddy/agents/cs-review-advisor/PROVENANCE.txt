## Extraction and local changes

- [Principles](skills/ponytail-principles/SKILL.txt): extracted The ladder, its root-cause paragraph, selected Rules and When NOT to be lazy. Retained the ordered necessity -> repository -> standard library -> platform -> installed dependency -> direct expression -> new implementation decisions. Changed one-line supremacy to readability/correctness; shared repairs require matching caller semantics; single implementations are investigation signals; existing project tests and explicit requirements remain binding; implementation imperatives become read-only recommendation guidance. Omitted persistent modes, intensity, code-first output, aggressive demand reduction and the single-self-check limit.
- [Review](skills/ponytail-review/SKILL.txt): extracted fixed-diff scope, Format/Tags and Boundaries. Added location/evidence/verification and contract-aware deletion criteria. Removed illustrative shortcuts that could weaken email validation, retries or public interfaces; omitted mandatory line savings and "Ship" conclusions. Tests and guardrails cannot be dismissed as complexity.
- [Audit](skills/ponytail-audit/SKILL.txt): extracted scope, Hunt, ranked Output and Boundaries. Requires explicit scope authorization, shares the private review tag definitions, treats hunt targets as candidates and reports only supported savings. Zero findings is not a release verdict.
- [Debt](skills/ponytail-debt/SKILL.txt): extracted marker Scan, per-marker Output, no-trigger and read-only Boundaries. Uses scoped rg searches and comment verification, records missing data/measurements as unknown and never equates zero markers with zero debt. Writes only pre-authorized report paths.

Each private method records its own extraction and adaptations. None was copied from or depends on public `cs-minimal`, `cs-code-review` or `cs-simplify`. This package does not include Ponytail runtime/hooks, persistence, modes, MCP, benchmarks, gain cards or public help/commands. No benchmark is represented as measured benefit for the reviewed repository.

## MySkills-authored protocol

The adjacent `cs-review-advisor.md` role, design-readiness review, classification/assignment drafts, architecture-question handoff, output integration, permissions and expert-verification lifecycle are local protocols, not upstream Ponytail capabilities. Ponytail review/audit explicitly exclude correctness, security and performance review.

The advisor only recommends; relevant experts independently assess advice as fully, partly or not acceptable. Blocking disagreements immediately go to the user through the host. Advice acceptance or user choice does not close a finding: repair plus expert verification on the repaired snapshot is required. The host owns orchestration and gates; architectural decisions stay with `cs-architect`.

## Packaging

These protocols are private to the adjacent advisor, not public skills. Resolve them from the installed agent location, never cwd or the original checkout. Preserve this provenance and LICENSE in all generated/installed resource trees. Private Markdown has no platform registration frontmatter, model declaration or slash-command entry.

The installed protocol files use `SKILL.txt` and `PROVENANCE.txt` (Markdown content). The CodeBuddy loader recursively discovers every `.md` under agents, including files without persona frontmatter; non-registration extensions prevent private methods and provenance being mistaken for agents. Upstream source names above remain `SKILL.md` for traceability.
