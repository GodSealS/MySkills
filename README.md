# Agent-Skills (multi-platform prompt pack)

24+ production-grade engineering workflow skills (ported from
[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills), MIT) adapted to install
into **Codex**, **CodeBuddy**, and **Gemini CLI** from a single source of truth.

> Single source of truth: `.codebuddy/` (skills, agents, commands, references).
> Everything else (`.gemini/`, `.agents/`, `.codex/`, and the top-level `skills/`, `agents/`,
> `references/`, `commands/`) is generated by `scripts/build-adapters.ps1`.

## Layout

```
.
├── skills/            # canonical neutral skills (name + description frontmatter)
├── agents/            # canonical personas
├── references/        # canonical checklists
├── commands/          # canonical slash commands (markdown)
├── .codebuddy/        # CodeBuddy home (SOURCE OF TRUTH — edit here)
│   ├── skills/ agents/ commands/ references/ hooks/ teams/
│   ├── AGENTS.md  settings.json  CODEBUDDY.md
├── .gemini/           # Gemini CLI adapter
│   ├── skills/        # auto-discovered skills
│   ├── commands/*.toml# slash commands
│   ├── agents/  references/
├── .agents/           # Codex skill adapter (auto-discovered)
│   └── skills/  references/
├── .codex/            # Codex adapter
│   ├── prompts/*.md   # slash-command-like prompts
│   └── agents/
├── AGENTS.md          # universal router (Codex auto-discovers this)
├── GEMINI.md          # Gemini persistent context
└── scripts/
    ├── build-adapters.ps1   # regenerate all adapters from .codebuddy/
    └── install.ps1          # copy a platform's files to a target location
```

## Install

### CodeBuddy
Copy `.codebuddy/` into your project (or `~/.codebuddy` for global):
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -Target codebuddy -Destination <your-project-or-home>
```

### Gemini CLI
Project-level (auto-discovered from the repo) — just keep `.gemini/` in your project root.
For a global install:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -Target gemini -Home
```
Or use Gemini's own installer against the canonical tree:
```bash
gemini skills install ./skills
```

### Codex
Project-level — keep `.agents/`, `.codex/`, and `AGENTS.md` in your project root (Codex
auto-discovers `.agents/skills` and `AGENTS.md`). For a global install:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -Target codex -Home
```

Install everything at once:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -Target all -Home
```

## Regenerate adapters
After editing anything under `.codebuddy/`, rebuild the platform trees:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-adapters.ps1
```
`cs-huashu-design` (CodeBuddy-only, browser/asset dependent) and `cs-code-query` (CodeBuddy/MCP-routing)
are excluded from the neutral adapters.
